Daylight for Zen

Packed Firefox add-on (5.3 MB). Temporary load in Zen or Firefox — it is not on AMO yet.

Download daylight.xpi or daylight.zip — same files
  1. Open about:debugging#/runtime/this-firefox
  2. Click Load Temporary Add-on…
  3. Select the downloaded .xpi
  4. Pin Daylight to the toolbar if it sits in the puzzle menu
